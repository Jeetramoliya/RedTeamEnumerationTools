Research candidates

RT-WIN-BACKUP-NTDS-3e6 · Backup/Restore privilege on a domain-reachable host -> NTDS/hive dump CORRELATED_PATTERN

Severity/Confidence: HIGH / POTENTIAL

Observed: A backup/restore privilege co-occurs with domain-sensitive context. Chain: read SAM/SYSTEM (or NTDS.dit on a DC) via the privilege -> secretsdump offline -> credentials.

Why unusual: SeBackupPrivilege lets a non-admin read any file (SAM/SYSTEM, or NTDS.dit on a DC) -> offline secret extraction -> domain credentials.

Known-pattern comparison: Matches a known pattern.

Evidence: RT-CRED-035c

Validation required: Remove SeBackup/SeRestore from non-tier-0 principals; monitor volume-shadow and raw-hive reads.

RT-AD-DELEG-UNUSUAL-cdd · Unusual delegation + credential-exposure combination RESEARCH_CANDIDATE

Severity/Confidence: HIGH / POTENTIAL

Observed: Delegation and a credential-exposure primitive co-occur on the same host. The combination is worth manual review as an unrecognized attack path.

Why unusual: Delegation combined with a nearby credential-read primitive can create an unexpected privilege boundary crossing that is not captured by a single-finding detection.

Known-pattern comparison: Matches a known pattern.

Evidence: RT-AD-8f89, RT-AD-7873

Validation required: Treat delegation hosts as tier-0; remove nearby credential-read exposure; validate the delegation target set.

RT-AD-UNCONSTRAINED-COERCE-1ea · Unconstrained delegation + coercion path to Domain Admin CORRELATED_PATTERN

Severity/Confidence: HIGH / POTENTIAL

Observed: Unconstrained delegation observed. Chain: coerce a privileged machine (e.g. a DC) to auth -> capture its TGT on the delegation host -> DCSync. End impact: Domain Admin.

Why unusual: A host with unconstrained delegation that can be made to authenticate (PetitPotam/PrinterBug/DFSCoerce) yields a DC TGT -> DCSync -> Domain Admin.

Known-pattern comparison: Matches a known pattern.

Evidence: RT-AD-8f89

Validation required: Remove unconstrained delegation; patch/disable coercion RPCs (MS-EFSRPC/MS-RPRN); mark DCs 'Account is sensitive and cannot be delegated'.

RT-AD-ESC8-RELAY-87d · AD CS present + relayable auth -> ESC8 web-enrollment relay CORRELATED_PATTERN

Severity/Confidence: HIGH / POTENTIAL

Observed: AD CS enterprise CA co-occurs with a relayable/coercible authentication condition. Review for ESC8 (web-enrollment NTLM relay) to a domain-controller certificate.

Why unusual: An enterprise CA plus a coercible/relayable auth path enables ESC8: relay a coerced DC to the CA web-enrollment endpoint, obtain a DC certificate, then TGT -> DCSync.

Known-pattern comparison: Matches a known pattern.

Evidence: RT-AD-8f89, RT-ADCS-597b

Validation required: Enable EPA + require HTTPS on CA web enrollment; enforce SMB/LDAP signing; disable NTLM where possible; patch coercion RPCs.

RT-CLOUD-AADCONNECT-HYBRID-43b · AAD Connect sync server -> on-prem <-> cloud identity pivot CORRELATED_PATTERN

Severity/Confidence: HIGH / POTENTIAL

Observed: Azure AD Connect (ADSync) present. Chain: compromise the sync host -> extract MSOL_/sync creds -> DCSync on-prem and/or manipulate cloud identities. End impact: on-prem + cloud identity pivot.

Why unusual: An AAD Connect sync server is tier-0: its MSOL_/sync account typically holds directory-replication rights (DCSync on-prem) and the sync bridges on-prem AD and Entra, enabling cross-boundary identity compromise.

Known-pattern comparison: Matches a known pattern.

Evidence: RT-CLOUD-ba70

Validation required: Treat the AAD Connect host as a Domain Controller (tier-0); restrict logon; rotate the MSOL_ account; monitor ADSync DB access.
